QUESTIONS

Before you decide.

Do I need Shopify Plus?

All plans can use supported public apps with Functions. Custom apps using Shopify Function APIs need Shopify Plus. Some features have other limits.

Can my old Script be copied exactly?

Not always. I will tell you if any old rule cannot be copied exactly.

Will checkout performance be affected?

Shopify Functions run inside Shopify. We still need to test the changes.
