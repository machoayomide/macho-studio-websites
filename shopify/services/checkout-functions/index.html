QUESTIONS

Before you decide.

Do I need Shopify Plus?

All plans may use public App Store apps with Functions. Shopify Plus is required for custom apps that contain Shopify Function APIs. Some capabilities have additional limits.

Can my old Script be copied exactly?

Not always. I explain any rule that has no direct match before building.

Will checkout performance be affected?

Shopify Functions run inside Shopify, but every customization still needs appropriate testing.
