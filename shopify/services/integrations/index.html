QUESTIONS

Before you decide.

Should I use an app or custom code?

If an app works well, I may suggest it. I use custom code when the app cannot do what you need.

Does stock sync instantly?

That depends on the platforms and plan. Some syncs use events; others run on a schedule.

Can you fully automate Amazon?

Many stock and order operations can be connected, but some listing tasks remain subject to Amazon's API rules.
