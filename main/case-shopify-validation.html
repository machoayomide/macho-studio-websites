PROJECT OVERVIEW / SHOPIFY / CUSTOM APP

Shopify B2B checkout validation app

Building checkout rules for a professional wholesale ordering journey.

PROJECT SNAPSHOT
Category
Shopify app / B2B commerce
Built with
Shopify CLI · Shopify Functions · JavaScript · GraphQL
Build status
Compiled, previewed, and released as an app version
Live client deployment
Not installed or verified
A private development project. Client details, company data and source code are not shared here.
01 / THE PROBLEM

Wholesale orders need clear rules.

A professional store needed buyers to follow a fixed opening-order plan and limit access to an introductory Starter Kit. Theme design alone cannot reliably enforce those rules at checkout.

02 / WHAT I BUILT

Checkout checks using Shopify Functions.

I created an extension-only Shopify app with JavaScript validation logic and a GraphQL input query. The function reads product and company metafields to check the cart against the professional-order rules.

  • Identify the five required opening-order products and check for at least three of each.
  • Check Starter Kit quantities and the company's redemption flag.
  • Use company-level flags to distinguish an opening order from later orders.
  • Keep the retail journey separate from the wholesale rules.
03 / PROGRESS & LIMITS

Built and compiled. Live rollout not claimed.

The custom GraphQL query generated types, the Shopify Function compiled, and the app loaded in a Shopify Plus development preview. An app version was released in the Shopify developer environment.

The app was not installed on the client's live store, and full real-buyer checkout scenario tests were not completed. It also does not automatically issue free tester stock or update company redemption flags after approval.

This case study shows a real technical build, not a claim of production use, increased sales or finished store automation. The order rules may also be handled through Shopify's staff-reviewed B2B draft orders.
